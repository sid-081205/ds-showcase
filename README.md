# audire

audire is a music analysis tool that captures your listening habits and translates them into mood profiles. by connecting spotify data to a custom pipeline using web scraping and kaggle datasets, it extracts acoustic features to visualize your music taste. the platform allows for comparison with other users to find overlaps in artists and genres while generating recommendations through a knn algorithm. the technology stack includes a react frontend with vite and tailwind css, a python flask backend for oauth2 and data processing, and sqlite for database management.
